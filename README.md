# From Card to Door

A narrated, interactive course on credentials, readers, protocols, card formats and troubleshooting in AXIS Camera Station Pro Secure Entry, for new Field Sales Engineers.

**Take the course:** https://mrdnlabs.github.io/axis-secure-entry-training/

- A four-voice, podcast-style story: two hosts, a customer and a talking Door solve the case of the locked-out CEO
- 24 slides, narration synced to on-screen animation, captions, and games: Pick the Card, Beep or Bust, Swipe Right on the Truth, Layer Drop and a customer-call boss level
- The previous single-narrator version is at [/v1/](https://mrdnlabs.github.io/axis-secure-entry-training/v1/)
- Keyboard: arrows or Space to move, **K** play/pause narration, **1–7** in Layer Drop, **O** all slides, **N** presenter notes

This repository holds the built site. The source (page, narration script and generator) lives in `presentations/secure-entry-credentials/` of the authoring repository; rebuild with `build-site.sh <output-dir>`.
